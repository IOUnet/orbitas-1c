# AGENTS.md — Orbitas для 1С:Предприятие

## Назначение
Репозиторий содержит расширение конфигурации 1С:Предприятие для подключения к Orbitas.

## Обязательные инварианты
- Разработка только через расширение конфигурации; типовую конфигурацию не изменять.
- Термины интерфейса: «организация», «контрагент», «реализация», «поступление», «обязательство Orbitas», «предложение взаимозачёта», «распоряжение на расчёт».
- Orbitas Core отвечает за графовый поиск, R/Q/S, блокировки, окончательную проверку и исполнение.
- 1С отвечает за исходные данные, сопоставление контрагентов, явное согласие пользователя и отражение подтверждённого исполнения.
- `settlement instruction != invoice paid`: появление распоряжения на расчёт не меняет бухгалтерское состояние документа.
- Внешний HTTP никогда не выполнять внутри транзакции записи учётного документа.
- Все исходящие операции идут через устойчивую очередь (outbox) и идемпотентный ключ.
- Повторная доставка входящих событий должна быть безопасной.
- Multi-company: все настройки, сопоставления и данные разделяются по Организации.
- Multicurrency: сумма и валюта передаются раздельно; не подменять валюту учёта валютой документа.
- Partial settlement и credit note/корректировки должны уменьшать остаток, но не переписывать историю Orbitas.
