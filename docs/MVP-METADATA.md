# Метаданные расширения MVP

Префикс всех новых объектов: `ORB_`.

## Регистры сведений

### ORB_НастройкиОрганизаций
Периодический: в пределах секунды.

Измерения:
- Организация

Реквизиты:
- ParticipantPassportID (Строка 128)
- БазовыйURL (Строка 512)
- ИдентификаторПодключения (Строка 128)
- СекретДоступа (ХранилищеЗначения)
- АвтоПубликация (Булево)
- Используется (Булево)
- ДатаПоследнейСинхронизации (Дата)

### ORB_СопоставленияКонтрагентов
Периодический: в пределах секунды.

Измерения:
- Организация
- Контрагент

Реквизиты:
- ParticipantPassportID
- Проверен
- ДатаПроверки

### ORB_СвязиОбязательств
Непериодический.

Измерения:
- Организация
- ИсходныйДокумент

Реквизиты:
- ObligationID
- OrbitasStatus
- ИсходнаяСумма
- ТекущийОстаток
- Валюта
- ДатаОбновления
- ПоследняяОшибка

### ORB_ОчередьИсходящих
Непериодический.

Измерение:
- ИдентификаторСообщения (UUID)

Реквизиты:
- Организация
- ИсходныйДокумент
- ТипОперации
- ИдемпотентныйКлюч
- ТелоJSON
- Состояние (new/processing/done/error/dead)
- Попыток
- СледующаяПопытка
- ПоследняяОшибка
- ДатаСоздания

Индексировать:
- Организация + ИдемпотентныйКлюч
- Состояние + СледующаяПопытка

### ORB_ВходящиеСобытия

## Регламентное задание

`ORB_ОбработкаОчередиOrbitas`:
- вызывает `ORB_Очередь.ОбработатьПакет()`;
- интервал MVP: 1 минута;
- исключить параллельную обработку одной записи;
- не блокировать запись типовых документов.

## Обработка «Рабочее место Orbitas»

Вкладки:
1. Подключение
2. Обязательства
3. Найти взаимозачёт
4. Предложения
5. Распоряжения на расчёт
6. Очередь обмена

Команды:
- Создать/привязать паспорт
- Синхронизировать
- Найти взаимозачёт
- Согласовать
- Отклонить
- Обновить состояния
- Отразить исполнение
